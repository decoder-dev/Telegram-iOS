# Telegram 13.1.2: локальная подготовка к RC

Дата: 1 ноября 2026. Ветка: `feature/donor-updates-20261101`.
Исходный main: `2eced049d263ae5e265e06e295b32c681a909ce7`.
Официальная база 13.1.2: `279f89e4d4`. Локальный merge: `3ff4de10b8`.

Статус: **RC BLOCKED**. Версия исходников — 13.1.2. Нового IPA, номера сборки, тега и опубликованного RC нет. Коммиты локальные; main не изменён. Старый опубликованный 13.1.1-4400-pre не содержит эти изменения.

## Что реализовано

- Перенесена официальная база Telegram 13.1.2; при разрешении конфликта Siri сохранены ограничения закрытого Архива и скрытых аккаунтов.
- Добавлены отсчёт 3–2–1, фокус по нажатию, сброс зума после жеста, 60 FPS и повышенное качество кружков. Выбор 60 FPS или качества включает нужную камеру даже без экспериментального переключателя; остальные пользователи сохраняют прежний режим. Доступность 0,5× определяется камерой и форматом. При отсутствии формата 60 FPS используется 30 FPS; одновременные две камеры в режиме 60 FPS отключены.
- Параметры записи неизменны в пределах открытой камеры. Параметры экспорта сохраняются вместе с видео, включая лимит размера; изменение настроек не меняет отложенный экспорт. Битрейт длинного кружка рассчитывается с запасом для звука и контейнера. Итоговый файл сверх лимита отклоняется с ошибкой. Облачные кружки загружаются маленькими частями; шифрованная отправка сохраняет свой путь.
- Отмена, закрытие камеры и смена состояния приложения инвалидируют отложенный старт. Отсчёт не стартует до готовности превью; зум, камера и вспышка остаются доступны. Подбор допустимого AAC-битрейта сохраняет совместимость с Bluetooth-микрофонами.
- Параллельные загрузки используют общий бюджет категорий одного аккаунта: до пяти небольших или двух больших/неизвестного размера файлов на датацентр; предзагрузка ограничена отдельно. Изменение настройки не отменяет уже идущие передачи и не удаляет скачанные диапазоны.
- Порядок аккаунтов сохраняется при завершении перетаскивания; удалённые и повторные ID отбрасываются, новые записи сохраняются. Скрытые закрытые аккаунты не показываются. Перестановка сохраняет текущий аккаунт и не вызывает повторную регистрацию push-токенов только из-за порядка.
- Добавлены скрытие спонсора прокси, кнопок AI и расширенного редактора, локальные значки своего профиля. Значки не меняют серверные флаги доверия. Настройки компоновщика и внешнего вида профиля вызывают обновление открытого интерфейса.
- Исправлены порядок ID новых строк меню и проверка официального API: вместо пустой выборки генерируемых Swift-файлов сравниваются существующие схема и её JSON с официальной базой.

Источники изменений и короткие release notes находятся в [CHANGELOG](../../CHANGELOG.md). Полный список файлов относительно исходного main — [13.1.2-files.txt](13.1.2-files.txt).

## Выполненные проверки

Окружение: Linux, Swift 6.2 в Docker. Swift-профили записи и экспорта прошли typecheck с `-warnings-as-errors`. 35 изменённых Swift-файлов прошли синтаксический разбор; это не проверка типов приложения с Apple SDK.

Повторный целевой прогон прошёл:

- `Tests/ClientAdditions/donor_updates.py`: компиляция и выполнение реальных политик настроек, выбора камеры, отсчёта, изменения аккаунтов, форматов захвата, размеров/битрейтов экспорта и Bluetooth-аудио; предупреждения считаются ошибками.
- `Tests/ClientAdditions/parallel_downloads.py`: размеры, граница 20 MiB, датацентры, занятые слоты других категорий, освобождение слотов, дубликаты и предзагрузка.
- `Tests/ClientAdditions/menu_layout.py`: 576 сочетаний языка, устройства и настроек; уникальные упорядоченные ID, переходы и сохранение настроек.
- `Tests/Camera/run.py`, `native_zoom.py`, `round_video_layout.py`: разрешения, отмена/подтверждение, пресеты линз и 154 варианта геометрии, включая клавиатуру; также проверена последовательность закрытия ввода и маршрутизация касаний зума.
- `Tests/Upstream13/audio_rich_text.py`, `donut_oct21.py`, `migration.py`, `passcode_codec.py`, шесть тестов `donut_profile_features` и две изменённые проверки `own_features`.
- Проверка границ Postbox, `git diff --check`, разбор YAML обоих изменённых workflows.

Первый расширенный прогон выполнил 48 команд Python-регрессии из release workflow: 36 прошли целиком. В оставшихся командах были неподдерживаемые Apple API (`CoreGraphics`, `Darwin`, CryptoKit, Objective-C, security-scoped URL, `os_unfair_lock`), отсутствовавшие в read-only контейнере исторические Git-объекты и устаревшие ожидания меню. Исторические объекты загружены, `passcode_codec` и изменённые ожидания повторно прошли. Два падения проверок UserDefaults связаны с отличающимся преобразованием чисел в Linux Foundation: отдельно воспроизведено, что сохранённый `[Int64]` не приводится обратно к `[Int64]`. Не меняли iOS-код или проверки ради зелёного Linux-прогона. Полный macOS-прогон остаётся обязательным; зелёный общий результат не заявляется.

Новые проверки добавлены в client regression и release workflow. Эти workflows для текущей ветки не запускались.
