# BananaGram: список фишек

Всё, что добавлено форком поверх Telegram iOS 13. Переключатели лежат в **Настройки → Extras** (в скобках id строки в `ForkExtrasController`). Всё, что не отмечено «по умолчанию включено», выключено.

## Внешний вид (зафиксирован в коде, не настраивается)
- Четыре встроенные темы: Classic White, Classic Black, BananaGram Cream, BananaGram Graphite; автопереключение по времени отключено.
- Пузыри в стиле iOS Messages: радиус 18/4, без хвостиков, цвет следует теме и акценту.
- Темы BananaGram оформляют и экран чата: пузыри, поле ввода, кнопка отправки, кнопка прокрутки вниз, фирменный узорный фон.
- Кнопки композера (микрофон, отправка, вложение) — круги 40 pt.
- Экран звонка следует теме: палитры для подключения, разговора и слабой связи, контраст 3:1 к белому тексту.
- Плашка звонка в чате — Liquid Glass: аватар, имя и таймер в стеклянной капсуле, у личных звонков аватар пульсирует в такт голосу.
- Строка «Кастомизация» в настройках открывает экран оформления (темы, обои, геометрия пузырей, иконки).

## Внешний вид (Extras)
- Бананчик наверху, показ бананчика, подпись BananaGram, «остров как у иконки» (1618, 1531, 1532, 1553, 1619).
- Стеклянные пузыри Liquid Glass, iOS 26+: включение, оттенок, блики сверху, по бокам, снизу (1900–1906).

## Список чатов и вкладки
- Компактный список, компактные превью, компактные названия папок, скрытие «Все чаты», запоминание последней папки (50–53, 59–62, 1499).
- Скрыть «Соединение…», эмодзи-статус, поиск, подсказки о днях рождения; заголовок по центру (1546–1549, 1512).
- Скрыть истории, архив, отключить камеру по свайпу, отключить создание историй (1773, 1774, 1790, 1930).
- Скрыть счётчик непрочитанных на папках, скрыть «печатает…» в личных чатах (1961, 1963).
- Панель вкладок: скрыть, широкая, встроенный поиск, поиск слева, вкладка контактов, папки внизу, свечение аватара и реакций (63, 64, 1499–1507).

## Сообщения и чат
- Счётчик пересылок в каналах, скрыть платные реакции, скрыть кнопку подарка, недавние эмодзи в реакциях, итоги опроса до голосования, дата оригинала у пересланных (1508, 1509, 1735, 1521, 1550, 1519).
- Цитата удалённого сообщения в ответе, точные счётчики без «1,2K», секунды во времени сообщений, широкие посты каналов, размер стикеров, скрыть панель реакций (1557, 1558, 65–69, 54).
- Вид чата: ответы без цвета имени, скрыть премиум-эмодзи в ответах, аватарки в упоминаниях, без своих фонов у чатов, скрыть «Поделиться», канал: «Обсудить» / скрыть нижнюю кнопку / скрыть реакции под постами (1720, 1711, 1703, 1713, 1716, 1719, 1717, 1718, 1931).
- Стикеры: скрыть время и галочки, ответ на стикер без цветов / эмодзи / фона (1721, 1542, 1712, 1700–1702).
- «В начало чата» в меню аватарки (1791).
- Служебные сообщения: отключение входов/выходов и правок, подтверждения реакции без вступления, ссылок Telegram и входа из предпросмотра (1940–1943).
- Отправка и правка: запятая после упоминания, отправка без превью ссылок, запрещённые GIF как видео, убрать пинги, отправка Enter, двойное касание, ID сообщения, раскрытие спойлеров, повтор и пересылка без автора в меню, хэштег ищет в этом чате (1710, 1511, 1520, 1533, 81, 82, 1802, 1800, 1801, 1803, 1518).
- Боты: скрыть «через бота», панель автоматизации, приветственный стикер (1510, 1513, 1517).
- Папки и закладки: выбор папки после вступления, недавние чаты (долгое «Назад»), закладки сообщений с тегами, локальное имя группы или канала (1825–1828).
- Ввод: формат по умолчанию, упоминание долгим нажатием на аватар (1850–1853); скриншот сообщений и пункт в меню (1910, 1911).
- Из Regram: массовый отзыв пригласительных ссылок, подтверждение открепления, остаться на последнем сообщении после обновления (1960, 1962, 1964).
- Быстрый перевод, сохранение в облако, выбор сообщений от автора, прокрутка к следующему чату, двойное касание для правки (88–99).
- Переводчик и расшифровка голосовых: выбор сервиса (85–87).

## Медиа и звонки
- Звонки: подтверждение перед звонком, встроенный микрофон, поддержание в фоне (80, 83, 84, 146, 149).
- Голосовые и кружки: пауза после воспроизведения, задняя камера кружка, запоминание камеры, подтверждение отправки; музыка как голосовое через меню трека (1515, 1516, 1544, 1545, 1559, 1612).
- Ссылки TikTok и Shorts: загрузка видео вместо ссылки, подпись «Скачано с…», запасной сервис tikwm (1613, 1554–1556, 1614, 1982).
- Стикеры и воспроизведение: только добавленные, без лимита недавних, форма стикеров, пауза при сворачивании, перемотка двойным касанием, кружок без сброса зума, ускоренная загрузка файлов (1750–1758).
- Превью ссылок через зеркала (X, Instagram, TikTok, Reddit, Bluesky, Pixiv), сохранение стикеров в Фото, сведения о медиа, качество видео по умолчанию (1860–1865).
- Качество исходящих фото (98, 99).
- Энергосбережение: Режим всегда включён (1912–1914).
- Пауза музыки при записи видео, голосового и при прослушивании голосового (2000–2004).

## Профиль
- Точное время «был(а) в сети», «был(а)» с давностью, серая точка для тех, кого нет в сети, исчезнувшие подарки (1551, 1714, 1552, 1543).
- ID в формате Bot API, взаимный контакт, дата создания чата, скрыть премиум-статусы и верификацию (1730–1734, 1739).
- Не открывать звёзды после продажи подарка, визуальная метка (видна только вам) (1980, 1981).
- Показывать другой номер в своём профиле (1736, 1737, 1740).
- Показ DC, ID профиля, насыщенность акцента (55–58).
- Эффекты: снег; локальные функции Premium (1541, 1603, 1604).

## Режим призрака
- Не читать сообщения и истории, не отправлять онлайн и «печатает», автоматический оффлайн, прочтение при действии, предупреждение перед историей, отложенная отправка (9–22).
- Скрывать «печатает…», «записывает голосовое/кружок», «отправляет файл» (1560–1562).
- Отправка без звука, предложение «Не читать истории» (1770–1772).

## Приватность и сохранение
- Режим стримера, мгновенный пароль, скрытие упоминаний и закреплённых (28–35).
- Резерв сессий, скриншоты в секретных чатах, кнопка TTL, не удалять заблокированные чаты (36–43).
- Сохранение удалённых и изменённых сообщений, история правок, сохранение медиа, пометки «удалено/изменено», экспорт и импорт базы, обход запрета скачивания, скрытие рекламы и заблокированных сообщений, чувствительный контент (110–133, 147, 148).

## Ядро и инфраструктура
- Редактор RichText и композер на `ChatInputContent`; расширенные сообщения через InstantPage V2 (заголовки, списки, таблицы, формулы, кнопки, документы, потоковое появление); подсветка кода libprisma.
- Rust-движок MTProto (выбирается в Debug Settings, MtProtoKit по умолчанию); телеметрия сети с анонимизацией.
- Прокси WEB (`tg://webproxy`) рядом с SOCKS5 и MTProxy.
- Список чата на CoreList (виртуализированный список по умолчанию для чата), отключается сервером.
- Встроенное приложение для Apple Watch (опционально для сборок на устройство).
- FFmpeg 8.1.2, SQLCipher 4.19 (SQLite 3.53.4), самовосстановление базы с защитой от удаления при блокировках.
- Починки по логам устройства: фоновая переиндексация не чаще раза в 20 часов, очистка кэшей при уходе в фон, ограничение повторов покупок и кошелька, запасной путь CallKit.
